# AURAV · Antes de volar

Juego WebXR de inspección pre-vuelo del Cessna 172SP, con doce estaciones obligatorias y un vuelo arcade asistido.

[Abrir el juego](https://ivan-i-aguilar.github.io/aurav-prevuelo/)

En Meta Quest Browser: esperar a que cargue el avión y elegir Entrar en realidad virtual. Gatillo para inspeccionar y elegir, agarre apuntando al suelo para teletransporte, stick derecho para girar. En PC: WASD, arrastrar para mirar, E para inspeccionar y N para la siguiente zona.

Prototipo lúdico. No sustituye una checklist aprobada, el POH ni instrucción de vuelo. La validación física en Quest 3S está pendiente.
